# Tunneling Lab

Hands-on cybersecurity labs for understanding network tunneling,
SSH tunneling and Ligolo-ng pivoting.

## Learning Path

- [ ] Lab 01 — Understanding Network Tunneling
- [ ] Lab 02 — SSH Local Port Forwarding
- [ ] Lab 03 — SSH Remote Port Forwarding
- [ ] Lab 04 — SOCKS Proxy
- [ ] Lab 05 — Ligolo-ng
- [ ] Lab 06 — Pivoting
- [ ] Lab 07 — Internal Network Enumeration

## Goal

The goal of this project is to understand how network tunnels work
before using tunneling and pivoting tools.

## Lab Environment

- Kali Linux
- Windows/Linux VM
- VirtualBox or VMware
- Isolated laboratory network

## Disclaimer

These labs are intended for authorized educational environments only.
